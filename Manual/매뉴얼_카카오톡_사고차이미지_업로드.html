카카오톡 사고차 이미지 견적상세에서 업로드 매뉴얼

작성자 김경태 · 작성일 2026-10-26

분류 프로그램을 켜 두고 카톡방에서 사진을 저장하면, 사진이 C:\kakaoimage\카톡방 이름 폴더로 자동 정리되고 폴더가 열립니다. 열린 폴더에서 IPN 견적 상세로 사진을 끌어다 놓아 업로드합니다.

1. 처음 한 번 설정

1-1. 압축 풀기

  1. 받은 카카오이미지자동분류.zip을 마우스 오른쪽 버튼으로 눌러 압축 풀기를 합니다.
  2. 풀린 폴더 안에 카카오이미지자동분류와 config 파일이 있는지 확인합니다.

1-2. config 설정

  1. config 파일을 마우스 오른쪽 버튼 → 연결 프로그램 → 메모장으로 엽니다.
  2. watch_folder 줄의 따옴표 안에 카카오톡 받은 파일 폴더 경로를 넣습니다.
    경로는 탐색기에서 문서 → 카카오톡 받은 파일 폴더를 열고 위쪽 주소창을 복사하면 됩니다.
  3. Ctrl+S로 저장하고 메모장을 닫습니다.

⚠ 붙여 넣은 경로의 \ 를 모두 / 로 바꿔야 실행됩니다.

✕ C:\Users\홍길동\Documents\카카오톡 받은 파일
○ C:/Users/홍길동/Documents/카카오톡 받은 파일

메모장에서 Ctrl+H → 찾을 내용 \, 바꿀 내용 / → [모두 바꾸기]

watch_folder 외의 다른 줄은 고치지 않습니다.

1-3. 실행해서 확인

카카오이미지자동분류를 더블클릭합니다.

  • 검은 창 마지막에 감시 시작이 보이면 설정 끝입니다.
  • 실행이 차단되면 → 1-4. 스마트 앱 컨트롤 끄기
  • "감시 폴더가 존재하지 않습니다" 또는 "config 문법 오류"가 나오면 → 1-2의 경로를 다시 확인합니다.

1-4. 스마트 앱 컨트롤 끄기 (차단될 때만)

  1. 시작 메뉴에서 Windows 보안을 엽니다.
  2. 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정으로 들어갑니다.
  3. 끄기를 선택하고, 카카오이미지자동분류를 다시 실행합니다.
한 번 끄면 다시 켤 수 없습니다. 백신(Windows Defender)은 그대로 동작합니다.

2. 사용하기

2-1. 분류 프로그램 실행

카카오이미지자동분류를 더블클릭합니다. 검은 창은 최소화만 하고 닫지 않습니다.

"이미 실행 중입니다"가 나오면 이미 켜져 있는 것이니 그대로 쓰면 됩니다.

2-2. 카톡방에서 사진 저장

카톡방을 더블클릭해 별도 창으로 띄우고, 사진을 열어 저장 버튼을 누릅니다.

2-3. 자동으로 열린 폴더 확인

사진이 C:\kakaoimage\카톡방 이름 폴더로 옮겨지고, 그 폴더가 자동으로 열립니다. 폴더는 처음 저장할 때 자동으로 만들어집니다.

2-4. 견적 상세에서 업로드

  1. IPN에서 해당 견적의 견적 상세 화면을 엽니다.
  2. 열린 폴더의 사진을 사고차 이미지 드래그 영역으로 끌어다 놓습니다. 여러 장을 한 번에 넣을 수 있습니다.
  3. [업로드 시작]을 누릅니다. 모든 썸네일이 "완료"로 바뀌면 끝입니다.
  4. 잘못 올린 사진은 썸네일 오른쪽 위의 ×를 눌러 삭제합니다.

사진은 jpg·jpeg·png·gif 형식, 한 장에 4MB 이하만 올릴 수 있습니다. "실패"가 나온 사진은 [업로드 시작]을 다시 누르면 다시 올라갑니다.

3. 꼭 기억할 점

  • 카톡방은 반드시 별도 창으로 띄워서 저장합니다.
  • PC를 켤 때마다 카카오이미지자동분류를 실행합니다. 창을 닫으면 분류가 멈춥니다.
  • 사진이 안 보이면 C:\kakaoimage\_unmatched 폴더를 확인합니다. 그래도 없으면 프로그램 폴더의 kakao_image.log를 담당자에게 보내 주세요.
